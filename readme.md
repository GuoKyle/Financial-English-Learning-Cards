# 口语精进｜双语研习卡片库

欢迎使用双语研习卡片库。这是一个专为口译和笔译实践（尤其是官方表达、政经金融文本）设计的极简学习工具。

## 🌟 核心特色

- **术语卡片 (瞬时提取训练)**
  采用经典的 3D 翻转卡片设计。专注于短语、核心词汇的瞬时提取（Instant Retrieval），点击卡片即可在双语间无缝切换。

- **句子卡片 (视译与句法研读)**
  摒弃了繁琐的翻页动画，采用**上下对照展开**模式。正面展示源语言，通过点击空白处，在下方直接展开目标语言及研习解析（Notes），方便直观比对长难句的句法结构与断句逻辑。

- **极简且专注的美学设计**
  去除了冗余的进度条和统计按钮，界面风格参考了高端数字笔记软件，采用纯粹的白/灰配色。希望你在面对密集的政经语料时，能保持视觉与心理的专注与清爽。

## 💡 使用指南

1. **直接访问**：在浏览器中打开主页链接即可开始研习。
2. **快捷操作**：
   - 鼠标点击：点击卡片中心区域即可翻页（术语）或展开参考译文（句子）。
   - 键盘控制：使用键盘的 `←` 和 `→` 键快速切换上一张/下一张，使用 `空格键` 翻转或展开卡片。
3. **无需登录**：工具纯本地运行，不收集任何练习数据，随时随地打开即用。

## 📂 结构说明

整个工具非常轻量，仅包含两个核心文件：
- `index.html`：交互界面与极简视觉的载体。
- `cards.json`：语料库本身。
